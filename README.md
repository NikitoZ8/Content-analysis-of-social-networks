# Контент-анализ мотивации и успеха в соцсетях

Проект анализирует Excel-таблицу с постами из соцсетей, считает частоты категорий и строит графики для сравнения платформ, типов успеха, эмоций, триггеров и других признаков.

Основной скрипт: `analyze_content.py`.

## Что делает скрипт

- читает данные из файла `Контент-анализ Мотивация Успех.xlsx`
- считает частоты и проценты по колонкам:
  `Платформа`, `Тип успеха`, `Эмоция`, `Триггеры`, `Аргументация`, `Призыв к действию`, `Образ успеха`
- строит столбчатые и круговые диаграммы
- сравнивает Telegram и TikTok по категориям
- строит тепловые карты связей между признаками
- считает дополнительные показатели по каналам, если в таблице есть колонка `Название канала`
- сохраняет PNG-графики, CSV-таблицы и итоговый Excel-отчет

## Структура проекта

- `analyze_content.py` - основной скрипт анализа
- `Контент-анализ Мотивация Успех.xlsx` - входные данные, не добавляются в Git
- `results_content_analysis/` - папка с результатами анализа, не добавляется в Git
- `.gitignore` - список файлов и папок, которые Git должен игнорировать

## Требования

- Python 3
- библиотеки `pandas`, `matplotlib`, `openpyxl`

## Установка зависимостей

Если используешь виртуальное окружение `venv`, выполни:

```powershell
.\venv\Scripts\python.exe -m pip install pandas matplotlib openpyxl
```

Если запускаешь обычным Python:

```powershell
python -m pip install pandas matplotlib openpyxl
```

## Как пользоваться

1. Помести файл `Контент-анализ Мотивация Успех.xlsx` в корень проекта.
2. Убедись, что в таблице есть нужные колонки:
   `Платформа`, `Тип успеха`, `Эмоция`, `Триггеры`, `Аргументация`, `Призыв к действию`, `Образ успеха`.
3. Запусти скрипт.

Через виртуальное окружение:

```powershell
.\venv\Scripts\python.exe analyze_content.py
```

Или обычным Python:

```powershell
python analyze_content.py
```

## Результаты

После запуска скрипт создаст папку `results_content_analysis` и сохранит туда:

- PNG-графики
- CSV-таблицы с частотами и сравнениями
- итоговый файл `summary_tables.xlsx`

Примеры результатов:

- `bar_Платформа.png`
- `bar_Тип успеха.png`
- `pie_Тип_успеха.png`
- `platform_compare_Тип успеха.png`
- `heatmap_Тип_успеха_Триггеры.png`
- `summary_tables.xlsx`

## Возможные ошибки

Если появляется ошибка `No module named ...`, значит не установлена одна из библиотек. Установи зависимости и запусти скрипт снова.

Если появляется ошибка про отсутствие Excel-файла, проверь, что файл лежит рядом со скриптом и называется именно:

```text
Контент-анализ Мотивация Успех.xlsx
```

Если файл называется иначе, измени значение `INPUT_FILE` в начале файла `analyze_content.py`.

## Git
