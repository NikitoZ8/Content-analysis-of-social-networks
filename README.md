# Контент-анализ мотивации и успеха в соцсетях

Проект анализирует Excel-таблицу с публикациями из Telegram и TikTok: нормализует данные, считает частоты смысловых категорий, сравнивает платформы и сохраняет графики, CSV-таблицы и сводный Excel-отчет.

Основной файл: `analyze_content.py`.

## Что делает скрипт

- читает входной файл `Контент-анализ Мотивация Успех.xlsx`
- проверяет наличие обязательных колонок
- нормализует названия платформ до `TG` и `TikTok`
- приводит колонку `Подписчики` к числовому формату
- разбивает многозначные категории в ячейках через запятую, точку с запятой или перенос строки
- считает частоты категорий в целом и отдельно по платформам
- строит процентные сравнения Telegram и TikTok
- строит тепловые карты связей `Тип успеха x Триггеры` и `Эмоция x Триггеры`
- считает долю публикаций с триггерами и прямым CTA
- сохраняет результаты в `content_analysis_output`

## Структура проекта

- `analyze_content.py` - основной скрипт анализа
- `Контент-анализ Мотивация Успех.xlsx` - входные данные
- `content_analysis_output/` - результаты запуска: графики, CSV-таблицы и Excel-отчет
- `.gitignore` - исключения для Git
- `venv/` - локальное виртуальное окружение, если используется

Файл с исходными данными, виртуальное окружение и папка с результатами исключены из Git.

## Требования

- Python 3
- библиотеки: `pandas`, `matplotlib`, `seaborn`, `openpyxl`, `numpy`

## Установка зависимостей

Через виртуальное окружение:

```powershell
.\venv\Scripts\python.exe -m pip install pandas matplotlib seaborn openpyxl numpy
```

Или через обычный Python:

```powershell
python -m pip install pandas matplotlib seaborn openpyxl numpy
```

## Формат входных данных

По умолчанию скрипт ищет файл:

```text
Контент-анализ Мотивация Успех.xlsx
```

Файл должен лежать в корне проекта рядом со скриптом. Если нужно использовать другой файл, измени значение `FILE_PATH` в начале `analyze_content.py`.

Обязательные колонки:

- `Платформа`
- `Название канала`
- `Подписчики`
- `Текст`
- `Тип успеха`
- `Эмоция`
- `Триггеры`
- `Аргументация`
- `Призыв к действию`
- `Образ успеха`

Колонка `Количество подписчиков` автоматически переименовывается в `Подписчики`.

## Запуск

Через виртуальное окружение:

```powershell
.\venv\Scripts\python.exe analyze_content.py
```

Или через обычный Python:

```powershell
python analyze_content.py
```

После успешного запуска в консоли появятся пути к папкам с результатами.

## Результаты

Скрипт создает папку `content_analysis_output` со следующей структурой:

```text
content_analysis_output/
  graphs/
  tables/
  summary_tables.xlsx
```

В `graphs/` сохраняются PNG-графики:

- `01_распределение_платформ.png`
- `02_Тип_успеха_частоты.png`
- `03_Эмоция_частоты.png`
- `04_Триггеры_частоты.png`
- `05_Аргументация_частоты.png`
- `06_Призыв_к_действию_частоты.png`
- `07_Образ_успеха_частоты.png`
- `08_Тип_успеха_проценты_по_платформам.png`
- `09_Эмоция_проценты_по_платформам.png`
- `10_Образ_успеха_проценты_по_платформам.png`
- `11_тепловая_карта_Тип успеха_x_Триггеры.png`
- `12_тепловая_карта_Эмоция_x_Триггеры.png`
- `13_доля_публикаций_с_триггерами.png`
- `14_доля_CTA_по_платформам.png`

В `tables/` сохраняются CSV-версии тех же расчетов с кодировкой `utf-8-sig`, удобной для открытия в Excel.

Файл `summary_tables.xlsx` содержит:

- лист `Исходные данные` с подготовленной таблицей
- листы с частотами по смысловым категориям

## Возможные ошибки

`FileNotFoundError: Файл не найден` означает, что Excel-файл отсутствует в корне проекта или называется иначе.

`В Excel не найдены нужные столбцы` означает, что в таблице нет одной или нескольких обязательных колонок.

`No module named ...` означает, что не установлена нужная библиотека. Установи зависимости из раздела выше и запусти скрипт снова.
